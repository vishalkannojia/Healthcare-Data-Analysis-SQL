# 🏥 Healthcare Data Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing healthcare operations data using SQL. It is designed using a relational database structure containing patient records, doctor details, appointments, treatments, and billing data.

The objective of this project is to generate valuable business insights by using SQL queries such as joins, aggregations, subqueries, CTEs, and window functions.

---

## 🗂️ Database Structure

The database contains **5 interconnected tables**:

-  **Patients**
-  **Doctors**
-  **Appointments**
-  **Treatments**
-  **Billing**
